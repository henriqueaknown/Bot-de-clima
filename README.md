# Discord Weather & Voice Bot

O **Discord Weather & Voice Bot** é uma solução desenvolvida em Python para integração entre o Discord, serviços meteorológicos e tecnologia de síntese de voz.

O sistema permite que usuários consultem as condições meteorológicas de uma determinada cidade diretamente por meio de um comando no Discord. As informações são obtidas através de uma API externa e apresentadas automaticamente no canal, proporcionando uma experiência rápida e prática.

Além da consulta meteorológica, o projeto conta com **síntese de voz**, permitindo que as informações obtidas sejam reproduzidas por áudio.

A aplicação combina **automação, integração com APIs, comunicação em tempo real e processamento de voz**, demonstrando a utilização do Python na criação de soluções integradas e automatizadas.

### Tecnologias

* Python
* Discord.py
* Requests
* pyttsx3
